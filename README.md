# Snake Game

Консольная игра «Змейка» на Python. Игрок управляет змейкой, собирает еду, увеличивает счёт и старается избежать столкновений со стенами и собственным телом.

## Требования

- Windows 10 или Windows 11.
- Python 3.12 или выше.
- [uv](https://docs.astral.sh/uv/).

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/verfess/snake-game-py.git
cd snake-game-py
```

Установите зависимости:

```bash
uv sync
```

## Запуск

Запуск со стандартными параметрами:

```bash
uv run python snake.py
```

Параметры по умолчанию:

| Параметр | Значение |
|---|---:|
| Ширина поля | 20 |
| Высота поля | 15 |
| Начальная скорость | 8 |

Размер игрового поля и начальную скорость можно задать самостоятельно:

```bash
uv run python snake.py --width 20 --height 15 --speed 8
```

Доступные аргументы:

| Аргумент | Описание |
|---|---|
| `--width` | Ширина игрового поля |
| `--height` | Высота игрового поля |
| `--speed` | Начальная скорость игры |

Все параметры должны быть положительными целыми числами. Для просмотра справки используйте:

```bash
uv run python snake.py --help
```

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки или WASD | Изменение направления движения |
| `P` | Пауза / продолжение игры |
| `Y` | Начать новый раунд после завершения игры |
| `N` | Завершить игру после завершения раунда |

## Правила игры

- За каждую съеденную еду начисляется одно очко.
- После сбора еды змейка увеличивается на одну клетку.
- Каждые 5 очков повышается уровень и увеличивается скорость.
- Столкновение со стеной или собственным телом завершает раунд.
- Если свободных клеток для появления еды не осталось, игра завершается.

## Тестирование

Запуск автоматических тестов:

```bash
uv run pytest
```

Проверка кода с помощью Ruff:

```bash
uv run ruff check .
uv run ruff format --check .
```

Проверка типов с помощью Mypy:

```bash
uv run mypy --strict src tests snake.py
```
